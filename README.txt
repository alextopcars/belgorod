ALEX.TOPCARS — форма заявок в Telegram

1. В репозитории GitHub Pages замени index.html этим файлом.
2. В Apps Script должен быть развёрнут обработчик doPost, а в свойствах скрипта должны быть BOT_TOKEN и CHAT_ID.
3. В форме используется URL опубликованного веб-приложения Apps Script.
4. После обновления сайта отправь тестовую заявку и проверь Telegram.

Важно: URL Apps Script сам по себе не является токеном Telegram. Не публикуй токен бота в HTML или GitHub.
Если ты создашь новое развёртывание Apps Script с другим URL, обнови action формы в index.html.
