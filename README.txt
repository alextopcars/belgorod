ALEX.TOPCARS — восстановленная версия на основе исходного дизайна

Восстановлен исходный макет чёрно-золотого сайта. Сохранены исходные секции, каталог, фильтры, мобильное меню, контакты и скрипты. Главное фото Porsche встроено прямо в index.html. Добавлен отдельный блок комиссионной продажи и пункт меню. Кнопки запросов в каталоге направлены на Telegram по номеру телефона.

Как загрузить:
1. Открой https://github.com/alextopcars/belgorod
2. Сначала убедись, что текущая версия сохранена в истории GitHub.
3. Загрузи index.html в корень репозитория, замени старый файл и нажми Commit changes.
4. Подожди несколько минут, затем обнови сайт через Ctrl+F5.

Примечание: ссылка Telegram по номеру может зависеть от настроек приватности аккаунта. Если не открывается, замени её на https://t.me/alex_topcars.
