# Интеграции alex.topcars — согласованные требования

## Подтверждено владельцем проекта
- Платежи принимает российское ИП на свой расчетный счет.
- Источники каталога: собственный аккаунт Avito и Telegram-канал.
- Авторизация: гостевой режим и вход по телефону/SMS.
- Оплата: как предоплата, так и полная стоимость автомобиля.
- Оформление заказа: через Telegram и через онлайн-оплату.

## Avito
Использовать только официальный Avito Business API и разрешённые аккаунту функции. API-ключи и секреты хранятся только в Supabase Edge Function secrets или другом серверном хранилище секретов. В приложении и GitHub их не размещать.

Первый релиз интеграции:
1. Проверка доступности API для аккаунта и категории объявлений.
2. Подключение OAuth/client credentials по документации Avito.
3. Импорт только собственных объявлений аккаунта.
4. Сопоставление по external_item_id + source.
5. Синхронизация цены, статуса, описания, URL и доступных медиа-полей.
6. Журнал ошибок и ручной запуск повторной синхронизации.

API Авито может требовать подходящий профессиональный тариф и разрешения. Перед реализацией нужно проверить конкретные права и API-методы в кабинете пользователя. API не следует считать средством импорта чужих объявлений.

Справка: https://developers.avito.ru/

## Telegram-канал
Для чтения новых публикаций и редактирований использовать Telegram Bot API. Бота необходимо добавить в канал и выдать ему необходимые права администратора. Обрабатывать channel_post и edited_channel_post через webhook. Хранить telegram_chat_id и message_id как внешний ключ. Вложения и текст нормализовать в карточку автомобиля; неполные записи отправлять в очередь проверки, а не публиковать автоматически.

Справка: https://core.telegram.org/bots/api

## Платежи ИП
Интеграция строится через интернет-эквайринг, договор с которым заключает ИП. Провайдера выбрать после проверки условий подключения, тарифов, допустимой модели продажи автомобилей, возвратов, чеков и расчётного счёта.

Обязательные сценарии:
- deposit: согласованная предоплата/бронь;
- full: полная стоимость;
- создание платежа только на сервере;
- сумма и назначение фиксируются в заказе до перехода на страницу оплаты;
- подтверждение только по проверенному webhook провайдера;
- статусы pending / succeeded / canceled / refunded;
- возврат и отмена платежа только серверной операцией с журналом;
- идемпотентность webhook и защита от повторной оплаты;
- не хранить карточные данные.

До включения реальных платежей согласовать юридическую схему сделки и документы: кто продавец автомобиля, кому принадлежит автомобиль, за что именно взимается предоплата, условия возврата, договор комиссии/купли-продажи и фискализация. Для автомобилей с оплатой полной стоимости требуется отдельная юридическая и операционная проверка, прежде чем включать этот сценарий в production.

Потенциальные провайдеры для оценки: ЮKassa и Т-Банк. Это не означает, что договор или подключение уже оформлены.

## SMS
Supabase Auth Phone OTP + российский SMS-провайдер, совместимость и тарифы проверить при выборе. OTP ограничить по частоте, сроку действия и количеству попыток. Вход по SMS не должен быть обязательным для просмотра публичного каталога.

## Что нужно предоставить для подключения
- Ссылка или @username Telegram-канала.
- Подтверждение, что пользователь может добавить бота администратором канала.
- Подтверждение наличия Avito Pro/подходящего тарифа и доступности API-ключей (секреты не присылать в чат и не коммитить).
- Название банка расчётного счёта ИП — для предварительного выбора эквайринга.
- Согласованные условия предоплаты: фиксированная сумма или процент, и когда/на каких условиях возвращается.
