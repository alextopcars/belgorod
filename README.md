# alex.topcars — сайт премиального автоподбора

Адаптивный одностраничный сайт на HTML, CSS и JavaScript без сборщика и сторонних JS-зависимостей.

## Возможности

- Тёмная тема с золотыми акцентами и адаптивная верстка.
- Мобильное меню, навигация по разделам.
- Каталог с фильтрами по марке, модели, цене, году и типу топлива.
- Избранное для автомобилей.
- Форма заявки, подготавливающая сообщение для Telegram.
- Услуги, этапы работы, контакты и SEO-метаданные.
- SVG favicon и автоматический деплой на GitHub Pages через GitHub Actions.

## Локальный запуск

Откройте `index.html` в браузере или используйте любой статический HTTP-сервер.

## Публикация через GitHub Pages

1. Откройте настройки Pages: https://github.com/alextopcars/belgorod/settings/pages
2. В разделе **Build and deployment** в поле **Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions** в репозитории и проверьте запуск **Deploy static site to GitHub Pages**.
4. После успешного деплоя сайт будет доступен по адресу https://alextopcars.github.io/belgorod/

После этого изменения в ветке `main` будут автоматически запускать публикацию.

## Перед реальным запуском

- Подтвердите цены, комплектации и наличие автомобилей: карточки в каталоге пока демонстрационные.
- Замените демонстрационные фотографии на утверждённые фотографии конкретных автомобилей.
- Добавьте реальную страницу политики обработки персональных данных и согласуйте текст формы.
- Если нужна автоматическая обработка заявок, подключите CRM или серверную форму: статический сайт сам по себе не записывает данные в базу.
