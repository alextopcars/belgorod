# alex.topcars — сайт премиального автоподбора

Адаптивный одностраничный сайт на чистом HTML, CSS и JavaScript. Никаких сборщиков или сторонних JS-зависимостей.

## Возможности

- Тёмная тема с золотыми акцентами.
- Адаптивное меню для мобильных устройств.
- Каталог с фильтрами по марке, модели, цене, году и типу топлива.
- Избранное для автомобилей.
- Форма заявки с подготовкой сообщения для Telegram.
- Блок услуг, этапы работы и контакты.
- SEO-метаданные и SVG favicon.

## Запуск локально

Откройте `index.html` в браузере либо используйте любой статический HTTP-сервер.

## Публикация через GitHub Pages

1. Откройте настройки репозитория: https://github.com/alextopcars/belgorod/settings/pages
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/(root)), затем нажмите **Save**.
4. После завершения публикации сайт будет доступен по адресу https://alextopcars.github.io/belgorod/

Публикация может занять несколько минут после первого включения Pages.

## Что обновить перед реальным запуском

- Подтвердить цены, комплектации и наличие автомобилей: демонстрационные карточки сейчас служат образцом каталога.
- Заменить демонстрационные фотографии на утверждённые фотографии конкретных автомобилей.
- Добавить настоящую страницу политики обработки персональных данных и согласовать текст формы.
- Если нужна автоматическая обработка заявок, подключить CRM или серверную форму: статическая версия сама по себе не отправляет данные в базу.
