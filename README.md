# TOPCARS — расширенный премиальный дизайн

Главная страница получила более выразительный hero-блок с крупным фото Porsche, золотой рамкой, стеклянными информационными плашками, зелёными CTA и лентой услуг. Сохранены каталог с фильтрами, услуги, этапы работы, Telegram, Instagram и телефон.

## Публикация
1. Распакуйте архив.
2. Откройте https://github.com/alextopcars/belgorod
3. Выберите **Add file → Upload files**.
4. Загрузите `index.html`, `favicon.svg`, `.nojekyll` и папку `assets` с `porsche-hero.jpg` в корень репозитория.
5. Подтвердите замену `index.html`, затем нажмите **Commit changes**.
6. Проверьте https://alextopcars.github.io/belgorod/

Нужно загружать папку `assets` вместе с HTML, иначе фото Porsche не появится. Стоимости и наличие в каталоге не подтверждены: карточки — примеры для запроса подбора.
