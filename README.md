# TOPCARS — чёрный, золотой и зелёный стиль

Адаптивный одностраничный сайт для GitHub Pages. Золотой цвет используется для заголовков, иконок и декоративных акцентов; зелёный — для кнопок Telegram.

## Состав
- `index.html` — вся страница, стили и небольшой скрипт мобильного меню.
- `favicon.svg` — иконка сайта.
- `.nojekyll` — отключение Jekyll для статических файлов.

## Как обновить существующий сайт
1. Скачайте архив и распакуйте его.
2. Откройте репозиторий TOPCARS в GitHub.
3. Нажмите **Add file → Upload files**.
4. Загрузите `index.html`, `favicon.svg`, `.nojekyll` из этой папки прямо в корень репозитория (не загружайте саму папку ZIP).
5. Подтвердите замену `index.html` при запросе и нажмите **Commit changes**.
6. Проверьте **Settings → Pages**: `Deploy from a branch`, `main`, `/(root)`. После публикации откройте URL в разделе Pages. Обновления могут появиться не мгновенно.

## Содержание сайта
Включены направления Корея / Китай / Европа, импорт под заказ, автовыкуп, Trade-in, комиссионная продажа, этапы сотрудничества и Telegram `@alex.topcars`. Все контактные кнопки открывают `https://t.me/alex.topcars`.

## Важно перед запуском
- Сайт статический; формы и CRM не подключены, кнопки отправляют клиента в Telegram.
- Фотографии подгружаются с Unsplash и требуют интернета. Они иллюстративные и не заявляют наличие конкретных автомобилей.
- Не указаны неподтверждённые цены, сроки, отзывы и гарантии.
- Проверьте тексты и добавьте необходимые юридические документы и данные бизнеса перед коммерческим использованием.
