## Как обновить сайт
1. Распакуйте архив.
2. Откройте репозиторий `https://github.com/alextopcars/belgorod`.
3. Нажмите **Add file → Upload files**.
4. Загрузите `index.html`, `favicon.svg` и `.nojekyll` прямо в корень репозитория.
5. Подтвердите замену существующего `index.html` и нажмите **Commit changes**.
6. Через несколько минут откройте `https://alextopcars.github.io/belgorod/`. Если видна старая версия, обновите страницу принудительно или откройте её в приватном окне.
