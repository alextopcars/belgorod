# alex.topcars — сайт премиального автоподбора

Адаптивный одностраничный сайт на HTML, CSS и JavaScript без сборщика и сторонних JS-зависимостей.

## Возможности

- Тёмная тема с золотыми акцентами и адаптивная верстка.
- Мобильное меню, навигация по разделам.
- Каталог с фильтрами по марке, модели, цене, году и типу топлива.
- Избранное для автомобилей.
- Форма заявки, подготавливающая сообщение для Telegram.
- Услуги, этапы работы, контакты и SEO-метаданные.
- SVG favicon и автоматический деплой на GitHub Pages через GitHub Actions.

## Локальный запуск

Откройте `index.html` в браузере или используйте любой статический HTTP-сервер.

## Публикация через GitHub Pages

1. Откройте настройки Pages: https://github.com/alextopcars/belgorod/settings/pages
2. В разделе **Build and deployment** в поле **Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions** в репозитории и проверьте запуск **Deploy static site to GitHub Pages**.
4. После успешного деплоя сайт будет доступен по адресу https://alextopcars.github.io/belgorod/

После этого изменения в ветке `main` будут автоматически запускать публикацию.

## Перед реальным запуском

- Подтвердите цены, комплектации и наличие автомобилей: карточки в каталоге пока демонстрационные.
- Замените демонстрационные фотографии на утверждённые фотографии конкретных автомобилей.
- Добавьте реальную страницу политики обработки персональных данных и согласуйте текст формы.
- Если нужна автоматическая обработка заявок, подключите CRM или серверную форму: статический сайт сам по себе не записывает данные в базу.


## Telegram-бот заявок

В репозитории добавлен обработчик бота в папке `bot/` и Blueprint `render.yaml`. Сам по себе код в GitHub бот не запускает — его нужно развернуть как веб-сервис.

1. Сначала отзовите любой токен, опубликованный в переписке, в @BotFather через `/revoke`, затем получите новый через `/token`.
2. На Render создайте новый Blueprint из этого репозитория и укажите новый `TELEGRAM_BOT_TOKEN` как secret environment variable.
3. `WEBHOOK_SECRET` будет сгенерирован Render автоматически; вручную задавать его не нужно.
4. После запуска откройте бота в Telegram и отправьте `/myid`; добавьте полученное числовое значение как `ADMIN_CHAT_ID` в Environment на Render, чтобы получать заявки.
5. В логах Render проверьте успешную установку webhook и протестируйте `/start`, `/start lead` и `/start services`.

Подробности — в [bot/README.md](bot/README.md). Секретные токены не должны попадать в репозиторий.


## Панель управления автомобилями

Каталог редактируется через Pages CMS: https://app.pagescms.org/

1. Войдите через GitHub и разрешите Pages CMS доступ к репозиторию `alextopcars/belgorod`.
2. Откройте репозиторий и выберите **Автомобили**. Настройка панели находится в `.pages.yml`, а данные каталога — в `data/cars.json`.
3. Добавьте запись автомобиля или измените существующую: марка, модель, фотография, наличие, год, двигатель, топливо, привод, цена и поле **Показывать на сайте**.
4. Чтобы временно убрать машину из каталога, снимите **Показывать на сайте**. Чтобы добавить фотографию, загрузите её через поле **Фотография**; файлы хранятся в `images/`.
5. Сохраните изменения коммитом в ветку `main`. GitHub Pages автоматически опубликует обновлённый каталог после выполнения workflow публикации.

Цены вводятся полным числом в рублях, например `4200000`, без пробелов. Данные из `data/cars.json` автоматически формируют карточки и фильтры марки, модели, года и топлива. Сайт остаётся статическим: пароль или токен GitHub в публичный код не добавляются.

Документация Pages CMS: https://pagescms.org/docs/quick-start/
