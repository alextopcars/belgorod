# AlexTopCarsLeadBot

Backend-обработчик Telegram-бота, связанного с сайтом alex.topcars.

## Что умеет бот

- Реагирует на /start, /start lead и /start services.
- Показывает меню услуг.
- Собирает пожелания по автомобилю, имя и контакт.
- Передаёт заполненную заявку в личный Telegram-чат владельца через ADMIN_CHAT_ID.
- Команда /myid показывает числовой Chat ID, необходимый для настройки уведомлений.
- Команда /cancel отменяет заполнение заявки.

## Почему одного username недостаточно

Ссылка вида https://t.me/AlexTopCarsLeadBot?start=lead лишь открывает бота и передаёт payload команде /start. Чтобы бот отвечал, нужен работающий обработчик и токен Telegram Bot API. Этот код — обработчик; его нужно развернуть как веб-сервис.

## Запуск на Render

1. Войди в Render и выбери **New → Blueprint**.
2. Выбери репозиторий `alextopcars/belgorod`. Render обнаружит файл `render.yaml`.
3. В настройках сервиса добавь `TELEGRAM_BOT_TOKEN` — новый токен существующего бота из @BotFather. Не публикуй этот токен в GitHub и не отправляй его в чат. `WEBHOOK_SECRET` Render сгенерирует автоматически; код безопасно преобразует его в допустимый формат Telegram.
4. Пока сервис ещё не принимает заявки администратора, сначала запусти его с токеном, открой в Telegram @AlexTopCarsLeadBot и отправь команду `/myid`. Бот покажет твой числовой Chat ID.
5. Добавь показанное число как `ADMIN_CHAT_ID` в Environment в Render. После сохранения Render перезапустит сервис.
6. Сам владелец должен один раз открыть бота и нажать Start. Проверь вкладку Logs в Render и адрес `/health`: `telegram_token_configured`, `admin_chat_configured` и `webhook_url_configured` должны быть `true`.
7. Протестируй `/start`, `/start lead` и кнопку заявки с сайта.

Render настроен через Infrastructure as Code в `render.yaml`. Сам сервис автоматически устанавливает webhook при запуске. Его публичный адрес Render передаёт в переменной RENDER_EXTERNAL_URL.

## Важные замечания

- Заявки хранятся в памяти только на время заполнения формы. Данные завершённой заявки отправляются администратору в Telegram; постоянной базы данных нет.
- Не включай в репозиторий токен бота или другие секреты. Используй только переменные окружения в панели хостинга.
- Если токен когда-либо попадёт в публичный доступ, немедленно отзови его через @BotFather и установи новый.
